# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/DSnext412-jpg/portfolio_001_.git
```

Go inside the project

```bash
cd portfolio_001_
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Build for production

```bash
npm run build
```
